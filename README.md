# BasketballStats: στατιστικά EuroLeague στα ελληνικά

Στατικό site που ενημερώνεται μόνο του κάθε βράδυ από τα δημόσια στατιστικά της EuroLeague. Παράγει περίπου 270 σελίδες σε κάθε γλώσσα (ελληνικά, αγγλικά, ισπανικά και σερβικά): βαθμολογία, 20 ομάδες, όλους τους παίκτες, Θερμόμετρο, Fantasy, Προγνωστικά, Άρθρα και πολιτική απορρήτου, μαζί με sitemap για τη Google.

## Τι περιέχει ο φάκελος

| Αρχείο / φάκελος | Τι είναι |
|---|---|
| `site.config.json` | Οι ρυθμίσεις σου: διεύθυνση site, στοιχεία ιδιοκτήτη, AdSense |
| `build.mjs` | Το script: τραβάει δεδομένα και φτιάχνει τις σελίδες στον φάκελο `dist/` |
| `src/` | Η εμφάνιση (`app.css`), η λειτουργία (`app.js`), το κέλυφος των σελίδων (`shell.html`), οι μεταφράσεις (`en.mjs`, `es.mjs`, `sr.mjs`) και τα εικονίδια της εφαρμογής |
| `articles/` | Τα άρθρα και τα προγνωστικά σου, ένα αρχείο `.md` το καθένα |
| `data/cache.json` | Τα τελευταία δεδομένα. Αν η EuroLeague δεν απαντήσει κάποιο βράδυ, το site χτίζεται από εδώ και δεν «σπάει» |
| `.github/workflows/update.yml` | Η αυτόματη βραδινή ενημέρωση στο GitHub |

Χρειάζεται μόνο Node.js 18 ή νεότερο. Δεν έχει άλλες εξαρτήσεις.

## 1. Ρυθμίσεις

Άνοιξε το `site.config.json` και συμπλήρωσε:

- **siteUrl**: η διεύθυνσή σου, π.χ. `https://basketballstats.eu`
- **owner** και **email**: εμφανίζονται στην πολιτική απορρήτου
- **adsenseClient** και **adsenseSlot**: άφησέ τα κενά μέχρι να εγκριθείς στο AdSense (βλ. βήμα 4)

## 2. Ανέβασμα online (δωρεάν, με GitHub Pages)

1. Φτιάξε δωρεάν λογαριασμό στο github.com και ένα νέο repository, π.χ. `basketballstats`.
2. Ανέβασε όλα τα αρχεία αυτού του φακέλου (Add file → Upload files). Ο φάκελος `.github` πρέπει να ανέβει κι αυτός.
3. Στο repository: **Settings → Pages → Source: GitHub Actions**.
4. Στην καρτέλα **Actions**, άνοιξε «Ενημέρωση site» και πάτησε **Run workflow**. Σε 3–5 λεπτά το site είναι online.
5. **Δικό σου domain:** στο Settings → Pages → Custom domain γράψε το domain (π.χ. `basketballstats.eu`). Στον καταχωρητή του domain πρόσθεσε τις εγγραφές DNS που σου δείχνει το GitHub. Τσέκαρε και το «Enforce HTTPS».

Από εκεί και πέρα, κάθε βράδυ στις 02:15 (ώρα Ελλάδας) το site ενημερώνεται μόνο του. Ενημερώνεται επίσης κάθε φορά που ανεβάζεις νέο άρθρο.

## 3. Google Search Console

1. Πρόσθεσε το domain στο search.google.com/search-console.
2. Στο **Sitemaps** δήλωσε: `https://ΤΟ-DOMAIN-ΣΟΥ/sitemap.xml`

## 4. Google AdSense

1. Κάνε αίτηση στο adsense.google.com με το domain σου. Βοηθάει να έχεις ήδη ανεβάσει μερικά άρθρα (βλ. παρακάτω), γιατί η Google θέλει και πρωτότυπα κείμενα, όχι μόνο πίνακες.
2. Στο AdSense: **Απόρρητο και μηνύματα → Ευρωπαϊκοί κανονισμοί** και ενεργοποίησε το μήνυμα συγκατάθεσης cookies. Είναι υποχρεωτικό για επισκέπτες από την ΕΕ.
3. Όταν εγκριθείς, φτιάξε μια «Διαφημιστική μονάδα προβολής» (responsive).
4. Βάλε στο `site.config.json`:
   - `adsenseClient`: π.χ. `ca-pub-1234567890123456`
   - `adsenseSlot`: ο αριθμός της μονάδας, π.χ. `9876543210`
5. Ανέβασε το αρχείο. Το site βάζει μόνο του μία διαφήμιση κάτω από την κεφαλίδα κάθε σελίδας και μία πριν από το υποσέλιδο. Φτιάχνει επίσης το `ads.txt` που ζητά το AdSense.

## 5. Άρθρα και προγνωστικά

Κάθε άρθρο είναι ένα αρχείο κειμένου στον φάκελο `articles/`. Ξεκίνα αντιγράφοντας το `_paradeigma.md`: εξηγεί όλα τα πεδία και τη μορφοποίηση. Ανέβασέ το στο GitHub, στον φάκελο `articles`, και σε λίγα λεπτά είναι online.

- Με `type: prognostiko` και `game: OLY-RED` (γηπεδούχος-φιλοξενούμενος), το προγνωστικό σου εμφανίζεται και στη σελίδα Προγνωστικά κάτω από τον αγώνα.
- Τα αρχεία που ξεκινούν με `_` δεν δημοσιεύονται. Το ίδιο ισχύει για όσα έχουν `draft: true`.

## 6. Tipsters

Κάθε tipster έχει ένα αρχείο στον φάκελο `tipsters/` (π.χ. `nikos.md`). Ξεκίνα αντιγράφοντας το `_paradeigma.md`, που εξηγεί τη μορφή. Κάθε επιλογή είναι μία γραμμή:

```
10 | OLY-RED | 1 | 1.55
```

(αγωνιστική | γηπεδούχος-φιλοξενούμενος | επιλογή | απόδοση). Μόλις τελειώσει ο αγώνας, το site βαθμολογεί μόνο του την επιλογή στο επόμενο βραδινό build. Ενημερώνει την κατάταξη (ποσοστό επιτυχίας, μονάδες, ROI) και τη σελίδα κάθε tipster. Οι επιλογές για αγώνες που δεν έχουν παιχτεί φαίνονται και στη σελίδα Προγνωστικά.

Για να προσθέσεις επιλογές: GitHub → φάκελος `tipsters` → άνοιξε το αρχείο του tipster → μολυβάκι (Edit) → πρόσθεσε γραμμές → Commit changes.

## 7. Αγγλική, ισπανική και σερβική έκδοση

Κάθε σελίδα υπάρχει και στα αγγλικά, στο `/en/` (π.χ. `basketballstats.eu/en/player/miles-norris/`), στα ισπανικά, στο `/es/` (π.χ. `basketballstats.eu/es/jugador/miles-norris/`), και στα σερβικά με λατινικούς χαρακτήρες, στο `/sr/` (π.χ. `basketballstats.eu/sr/igrac/miles-norris/`). Οι εκδόσεις συνδέονται μεταξύ τους για τη Google (hreflang), και πάνω δεξιά υπάρχουν κουμπιά ΕΛ / EN / ES / SR.

- Τα στατιστικά, οι πίνακες και οι εκτιμήσεις μεταφράζονται αυτόματα. Τα λεξικά είναι στα `src/en.mjs`, `src/es.mjs` και `src/sr.mjs`. Αν προσθέσεις ελληνικό κείμενο στο `src/app.js` ή στο `src/shell.html`, πρόσθεσε τη μετάφρασή του εκεί. Το build γράφει στην οθόνη ό,τι έμεινε αμετάφραστο.
- **Άρθρα**: για αγγλική εκδοχή βάλε `title_en` (και προαιρετικά `description_en`) στην αρχή του αρχείου, και στο τέλος του ελληνικού κειμένου μια γραμμή `=== English ===` με το αγγλικό κείμενο από κάτω. Για ισπανικά: `title_es` και γραμμή `=== Español ===`. Για σερβικά: `title_sr` και γραμμή `=== Srpski ===`. Χωρίς αυτά, το άρθρο εμφανίζεται μόνο στα ελληνικά.
- **Tipsters**: κάτω από την ελληνική ανάλυση μιας επιλογής, μια γραμμή `EN:` και από κάτω η ανάλυση στα αγγλικά, μια γραμμή `ES:` για τα ισπανικά και μια γραμμή `SR:` για τα σερβικά. Για το βιογραφικό: `bio_en`, `bio_es` και `bio_sr`.

## Εναλλακτικά: στο δικό σου hosting

Αν ο πάροχός σου υποστηρίζει Node.js και cron (π.χ. cPanel με «Setup Node.js App»), ανέβασε τον φάκελο και βάλε cron κάθε βράδυ:

```
15 2 * * * cd ~/basketballstats && node build.mjs && rsync -a --delete dist/ ~/public_html/
```

Αν το site μπει σε υποφάκελο (π.χ. `/stats/`), βάλε `"base": "/stats/"` στο `site.config.json`.

## Δοκιμή στον υπολογιστή σου

```
node build.mjs            # με φρέσκα δεδομένα
node build.mjs --offline  # με τα αποθηκευμένα δεδομένα
cd dist && python3 -m http.server 8080   # μετά άνοιξε http://localhost:8080
```

## Σημειώσεις

- Πηγή δεδομένων: τα δημόσια feeds στατιστικών της EuroLeague. Το site δεν συνδέεται με την EuroLeague. Πριν βάλεις διαφημίσεις, διάβασε τους όρους χρήσης της για τα στατιστικά.
- Σε κάθε νέα σεζόν άλλαξε το `season` στο `site.config.json` (π.χ. `E2027` για τη σεζόν 2027-28). Αν αλλάξουν οι ομάδες, πρόσθεσέ τες στη λίστα `TEAMS` στην αρχή του `build.mjs`.

## 8. Τραυματίες

Στο αρχείο `traumaties.md` γράφεις τους τραυματίες, μία γραμμή ο καθένας (οδηγίες μέσα στο αρχείο).
Αυτοί παίρνουν κόκκινο ✚ δίπλα στο όνομα σε όλο το site και βγαίνουν από τις προτάσεις του Fantasy.
Όποιος έχει χάσει τους 2 ή περισσότερους τελευταίους αγώνες της ομάδας του παίρνει αυτόματα πορτοκαλί ✚.
Μόλις ένας παίκτης ξαναπαίξει, το ✚ φεύγει μόνο του.

## 9. Γραμμές παικτών, «με και χωρίς», σελίδες αγώνων

- **Γραμμές παίκτη** (σελίδα παίκτη): πόσες φορές πέρασε ένα όριο σε πόντους, ριμπάουντ, ασίστ, Π+Ρ+Α, τρίποντα ή PIR, σε όλη τη σεζόν, στους 5 τελευταίους, εντός και εκτός έδρας και με τον επόμενο αντίπαλο.
- **Με και χωρίς** (σελίδα ομάδας και παίκτη): το ρεκόρ της ομάδας με και χωρίς κάθε βασικό παίκτη, και ποιος παίρνει τα λεπτά του όταν λείπει.
- **Σελίδα αγώνα** για κάθε αγώνα της σεζόν (/agonas/, /en/game/, /es/partido/, /sr/utakmica/): πρόβλεψη ή τελικό, φόρμα, απουσίες, βασικοί παίκτες, σύγκριση ομάδων, τα μεταξύ τους και τα προγνωστικά μας.
- Τα κείμενα αυτών των ενοτήτων βρίσκονται στο `build.mjs` (σταθερά `UI`), σε όλες τις γλώσσες.
